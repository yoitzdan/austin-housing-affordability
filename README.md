# Austin Housing Affordability Analysis

An end-to-end data analytics project examining housing affordability in Austin compared with Dallas, Houston, and San Antonio from 2015–2024.

## 🎯 Project Objective

How has housing affordability in Austin changed relative to income, rent, mortgage rates, and local economic conditions?

## 🛠️ Tools

- **Python (pandas):** Data cleaning, transformation, and feature engineering
- **MySQL:** Querying, aggregation, joins, CTEs, and window functions
- **Power BI:** Data visualization, DAX measures, and interactive dashboard development

## 📁 Data Sources

- **Zillow:** Home values and rent
- **U.S. Census ACS:** Median household income
- **FRED:** 30-year fixed mortgage rates
- **BLS/FRED:** Metro-area unemployment rates

## 🔄 Workflow

**Raw Data → Python → MySQL → Power BI → Insights**

## 📈 Key Findings

- Austin home values rose **74.1%** from 2015–2024, compared with **62.3%** growth in median household income.
- Austin had the **highest 2024 price-to-income ratio** among the four cities at **6.05**.
- Austin's estimated mortgage payment burden increased from **28.4% in 2021** to **37.6% in 2024**.

## 📌 Methodology

Housing affordability was evaluated using home values, rents, median household income, and estimated mortgage payments. Mortgage payments assume a **20% down payment and a 30-year fixed-rate mortgage**.

Housing and income data are measured at the **city level**, while unemployment data are measured at the **metro-area level** and are used as broader economic context.
