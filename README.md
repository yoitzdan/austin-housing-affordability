Austin Housing Affordability Analysis

An end-to-end data analytics project examining housing
affordability in Austin compared with Dallas, Houston,
and San Antonio from 2015–2024.

🎯 Project Objective
How has housing affordability in Austin changed relative
to income, rent, mortgage rates, and local economic conditions?

🛠 Tools
Python — data cleaning, transformation, feature engineering
MySQL — querying, aggregation, joins, window functions
Power BI — data visualization, DAX, interactive dashboard

📁 Data Sources
• Zillow — home values and rent
• U.S. Census ACS — median household income
• FRED — mortgage rates
• BLS/FRED — unemployment rates

🔄 Workflow
Raw Data → Python → MySQL → Power BI → Insights

📈 Key Findings
• Austin home values rose 74.1% from 2015–2024,
  compared with 62.3% median household income growth.

• Austin had the highest 2024 price-to-income ratio
  among the four cities at 6.05.

• Estimated Austin mortgage burden increased from
  28.4% in 2021 to 37.6% in 2024.
